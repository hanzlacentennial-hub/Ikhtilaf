
# Ikhtilaf

Ikhtilaf is a full-stack web platform being developed for Ikhtilaf, a social justice book club focused on literature, justice and equality.

The platform is designed to provide a central and welcoming space for members to explore current and archived books, discover new reads, recommend books, and stay connected with the book club online.

## Tech Stack

### Frontend
- React
- TypeScript
- Vite

### Backend
- Python
- FastAPI

### Database
- PostgreSQL

## Current Features

- Multi-page book club website
- Current and archived book information
- Local and POC-owned bookstore resources
- REST API built with FastAPI
- React frontend connected to the Python backend through API requests
- PostgreSQL integration for storing and retrieving book club data
- Member registration and login using hashed passwords
- Session-based authentication with login and logout
- Book search by title or author
- Individual book lookup by ID
- Random book selection
- Book count

## In Development

- Displaying books from the database on the website
- Member profiles and account management
- Book recommendations submitted by members
- Voting for upcoming reads
- Member discussions and conversations between meetings
- Administrative tools for managing books and member contributions

## Development Approach

Ikhtilaf is being developed with a focus on software design and user experience. I regularly communicate with book club members to understand their needs, gather feedback, and explore ideas for new features.

I also bring my own ideas into the development process, balancing technical decisions with what would make the platform useful and accessible to its members.

The goal is to build a platform that reflects the needs of the community while continuing to improve it through feedback and development.
